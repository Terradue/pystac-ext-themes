# Themes PySTAC extension

Read and write thematic classifications on STAC Catalogs, Collections, and Items with `pystac-ext-themes`. Themes group concepts under a controlled vocabulary or knowledge organization system identified by a scheme URI.

```bash
python -m pip install pystac-ext-themes
```

- [Create an Item with themes](tutorials/first-steps.md) and round-trip its metadata.
- [Update themes and Collection summaries](how-to/use-extension.md).
- [Look up fields](reference/fields.md) and [browse the Python API](reference/api.md).
